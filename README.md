<a name="game-introduction"></a>
## 🕹️ Game Introduction

This game combines **tower defense mechanics with real-time character action gameplay**.  
Players place turrets to defend the castle while directly controlling a character to fight monsters attempting to destroy the castle walls.

This project is a **3D upgrade of the previous title "Rise Of Citadel"**, featuring improved visual effects and expanded gameplay mechanics.

The project was developed during the **2022 Chungnam Game Jam**.  
https://www.youtube.com/watch?v=BxrM-qGS3-Q

<a name="game-features"></a>
## ⭐ Game Features

| Feature | Description |
|------|------|
| 🏰 Action + Defense Gameplay | Combines turret-based defense systems with direct character-controlled combat |
| ⚔️ Real-Time Combat | Players directly control a character to defeat monsters attacking the castle |
| 🛡️ Turret Strategy System | Strategic turret placement helps defend against incoming enemies |
| 🎮 3D Upgrade | Reimagines the original *Rise Of Citadel* in 3D with enhanced visuals and gameplay features |
